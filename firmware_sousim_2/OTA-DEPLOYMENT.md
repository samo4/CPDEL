# OTA (Over-The-Air) Build & Deployment

Automated build, versioning, and deployment of ESP32-S2 firmware via GitHub Releases (powered by GitHub Actions).

## Quick Start

### 1️⃣ **First Time Setup**

```bash
# No manual setup needed!
# GitHub Actions automatically builds and publishes on tag push.
# Just commit your code and push version tags.
```

### 2️⃣ **Trigger Build & Deploy**

```bash
# Create and push a version tag
git tag v1.0.0
git push origin v1.0.0

# GitHub Actions automatically:
# 1. Builds firmware from source
# 2. Creates a GitHub Release with artifacts
# 3. Generates OTA manifest for device update checks
```

**Monitor the build:**

- Go to your repo's **Actions** tab
- Watch the "Build and Deploy OTA Firmware" workflow
- Once complete, check **Releases** for published artifacts

## How It Works

### Build Process

1. **Clean** (optional) - Remove previous build artifacts
2. **Compile** - Run `idf.py build` to compile ESP-IDF project
3. **Extract** - Find the compiled `.bin` file
4. **Checksum** - Calculate SHA256 hash for integrity verification
5. **Manifest** - Create JSON manifest with version, timestamp, checksums

### Deployment Process (GitHub Actions)

1. **Checkout** - Clone repository at tag
2. **Setup** - Install Python, ESP-IDF, build tools
3. **Build** - Compile firmware with `idf.py build`
4. **Package** - Generate manifests and calculate checksums
5. **Release** - Create GitHub Release with artifacts
6. **CDN** - Firmware available at `https://github.com/{repo}/releases/download/{tag}/firmware.bin`

### Output Structure

```
ota-artifacts/
├── 1.0.0/
│   ├── firmware.bin          # The compiled binary
│   ├── manifest.json         # Metadata and checksums
│   └── update-info.json      # Simple update info
├── 0.9.0/
│   └── ...
└── current → 1.0.0/          # Symlink to latest version
```

## Configuration

### GitHub Actions (Automatic)

No manual setup needed! The workflow at `.github/workflows/ota-build.yml` automatically:

- Triggers on version tag pushes (e.g., `v1.0.0`)
- Builds ESP-IDF firmware
- Creates GitHub Releases with all artifacts
- Generates OTA manifests with checksums

**That's it!** Just push tags and GitHub Actions handles the rest.

## Manifest Format

### `manifest.json`

```json
{
  "version": "1.0.0",
  "timestamp": "2024-01-15T10:30:00Z",
  "project": "sousim2",
  "target": "esp32s2",
  "files": {
    "firmware": {
      "filename": "firmware.bin",
      "size": 2097152,
      "sha256": "abc123...def456"
    }
  },
  "metadata": {
    "buildSystem": "esp-idf",
    "buildHost": "LAPTOP-ABC",
    "buildUser": "developer"
  }
}
```

### `update-info.json`

Simple format for device polling (generated by GitHub Actions):

```json
{
  "latestVersion": "1.0.0",
  "url": "https://github.com/{OWNER}/{REPO}/releases/download/v1.0.0/firmware.bin",
  "checksum": "abc123...def456",
  "timestamp": "2024-01-15T10:30:00Z"
}
```

## Device-Side Implementation (ESP32-S2)

### Simple Update Check

```c
#include <esp_http_client.h>
#include <mbedtls/sha256.h>

typedef struct {
    char version[32];
    char url[256];
    char checksum[65];  // SHA256 hex
} ota_update_info_t;

// Call periodically to check for updates
bool check_ota_update(const char* check_url, ota_update_info_t* out_info) {
    esp_http_client_config_t config = {
        .url = check_url,  // e.g., https://github.com/{OWNER}/{REPO}/releases/download/v1.0.0/update-info.json
        .method = HTTP_METHOD_GET,
    };

    esp_http_client_handle_t client = esp_http_client_init(&config);
    esp_err_t err = esp_http_client_perform(client);

    if (err == ESP_OK) {
        // Parse JSON response and populate out_info
        // Compare version with current FIRMWARE_VERSION
        // If newer, trigger OTA update
    }

    esp_http_client_cleanup(client);
    return err == ESP_OK;
}

// Perform OTA update
void perform_ota_update(const char* firmware_url) {
    esp_https_ota_config_t ota_config = {
        .http_config = &(esp_http_client_config_t){
            .url = firmware_url,
            .crt_bundle_attach = esp_crt_bundle_attach,
        },
        .partial_http_download = true,
        .max_http_request_size = 512,
    };

    esp_err_t ret = esp_https_ota(&ota_config);
    if (ret == ESP_OK) {
        esp_restart();
    } else {
        ESP_LOGE("OTA", "OTA update failed: %s", esp_err_to_name(ret));
    }
}
```

## CI/CD Integration

### GitHub Actions Example

```yaml
name: OTA Build & Deploy

on:
  push:
    tags:
      - "v*" # Trigger on version tags

jobs:
  build-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python & ESP-IDF
        uses: esp-rs/esp-idf-action@v1
        with:
          esp-idf-version: v4.3.3
          targets: esp32s2

      - name: Build firmware
        run: |
          cd firmware_sousim_2/esp
          idf.py build

      - name: Create Release
        uses: softprops/action-gh-release@v1
        with:
          files: firmware_sousim_2/esp/build/esp32s2/esp-idf/build/firmware.bin
          body: "OTA Firmware Release ${{ github.ref_name }}"
```

## Troubleshooting

### \u274c Build fails locally

```bash
# Check ESP-IDF is configured
. $IDF_PATH/export.sh

# Try clean build
cd firmware_sousim_2/esp
idf.py fullclean
idf.py build

# Check build output
ls -la esp/build/*.bin
````

### ❌ GitHub Release download fails

```bash
# Verify release exists
gh release list
gh release view v1.0.0

# Check GitHub Actions workflow status
gh run list

# Test download manually
curl -L https://github.com/{OWNER}/{REPO}/releases/download/v1.0.0/firmware.bin -o test.bin
```

### ❌ Device can't download firmware

1. Verify GitHub Release is public
2. Check URL in update-info.json points to correct release
3. Test download: `curl -L https://github.com/OWNER/REPO/releases/download/v1.0.0/firmware.bin -o test.bin`
4. Verify checksum matches manifest

### ❌ Version not updating

```bash
# Check git tags
git tag -l

# Create new tag
git tag v1.0.1
git push origin v1.0.1

# Watch GitHub Actions build
gh run watch
```

## Advanced Usage

### Alternative Hosting Options

GitHub Releases is the default. If you prefer alternatives:

#### GitHub Pages

```bash
git checkout --orphan gh-pages
mkdir -p ota-artifacts
cp firmware_sousim_2/esp/build/esp32s2/esp-idf/build/firmware.bin ota-artifacts/
git add ota-artifacts/
git commit -m "OTA artifacts for $VERSION"
git push -u origin gh-pages
```

Device URL: `https://{USERNAME}.github.io/{REPO}/ota-artifacts/firmware.bin`

#### Self-Hosted or AWS S3

Create a custom deployment script that uploads to your infrastructure instead of GitHub.
